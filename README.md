# Ukázkový firemní web – Třetí roh

Ukázkový web kavárny a pekárny **Třetí roh**, vytvořený jako prezentace možností tvorby webových stránek pro studenty během Dne otevřených dveří.

🌐 **[Otevřít web](https://simiikqqq.github.io/ukazkovy-web-pro-studenty-dod/)**

## O projektu

Jedná se o fiktivní firemní web kavárny a pekárny. Slouží především jako ukázka toho, jak může vypadat moderní webová prezentace firmy a jaké funkce může obsahovat.

## Obsah webu

- Představení podniku.
- Nabídka jídel, nápojů a pečiva.
- Fotogalerie.
- Informace o podniku a jeho příběhu.
- Kontaktní údaje a otevírací doba.
- Formulář pro rezervaci stolu.

## Použité technologie

- HTML
- CSS
- JavaScript
- GitHub Pages

## Spuštění projektu

Web je dostupný online prostřednictvím GitHub Pages.

Pro lokální spuštění stačí stáhnout repozitář a otevřít soubor `index.html` v internetovém prohlížeči.
